## 🌐 Website

The Factory Logic website is built with Astro and deployed to GitHub Pages:

**https://andydeng-automation.github.io/factory-logic/**

### Run locally

```sh
pnpm install
pnpm dev
```

### Publish

The `Deploy Astro site to GitHub Pages` workflow builds and publishes the site when changes are pushed to `main`. In the repository settings, set **Settings → Pages → Build and deployment → Source** to **GitHub Actions**. The project uses pnpm; run `pnpm build` to create the production site locally.

### Add a fieldnote

Create a Markdown file in `src/content/articles/` with this frontmatter:

```yaml
---
title: "Your article title"
description: "A short summary for the homepage and search results."
category: Automation # Automation, Machine Vision, Manufacturing, or Projects
pubDate: 2026-10-15
draft: false
---

Write the article in Markdown here.
```

The filename becomes the article URL. Set `draft: true` to keep a note off the published site while you work on it.
